# mormot2-monitor-dev
[wip|test] Automated monitoring of new commits, AI analysis, and documentation writing.

Review official mORMot2 commits, deprecation notices, release notes, issue/status communications, and other authoritative project updates from the past day.  
Focus only on changes that could affect Delphi/FPC/mORMot2 backend work, especially mORMot2 v2.x APIs, REST/SOA, ORM, serialization, database layers, HTTP clients/servers, interfaces/contracts, compiler compatibility, deprecations, breaking changes, bug fixes, and security-related changes. Ignore trivial churn.  
For each meaningful change, summarize what changed, explain the likely impact on an existing Delphi backend, and give concise review-ready questions or concrete next steps.  
Prefer official mORMot2/GitHub/Synopse sources and clearly distinguish confirmed changes from interpretation. If there are no meaningful changes, state that briefly.
